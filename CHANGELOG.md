# Changelog

All notable changes to OpenPacketLab are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Discrete-event network simulator with Ethernet, ARP, IPv4, ICMP, UDP and TCP.
- Switching: MAC learning, VLANs, 802.1Q trunks, spanning tree, port security, SVIs and Layer 3 switching.
- Routing: static, RIPv2, OSPF and EIGRP; subinterfaces, loopbacks and serial links; NAT and ACLs.
- Services: DHCP (server, client, relay), DNS, HTTP and syslog.
- IOS-style command line with help, completion, configuration files, Telnet and SSH.
- PC command prompt, IP configuration, web browser and terminal apps.
- Apple-style interface with light and dark mode, simulation mode, command palette, backups and sample labs.
- Desktop app for macOS, Windows and Linux (Tauri 2) with `.opl` file association.
- Docker image and Portainer stack.
- Release workflow, package manifests and the `opl` dev tool.
